Anchor the digest on Solana

qal anchor evidence.qev --network devnet

What goes on-chain

  • 32-byte vault digest
  • Schema hash + optional parent digest
  • Issuer & controller wallets
  • Active / revoked / superseded status

What never goes on-chain

  • Plaintext document
  • QEV passphrase
  • Derived keys / content keys
  • Sensitive unencrypted labels

Verify a vault

Step 1: pick the vault file. Step 2: add the receipt if you have one. Step 3: hit Verify. Hashing stays in this tab.

Chain verify only works when the QAL program is live on that network. Right now public Devnet deploy is incomplete — you can still load a vault and see local hashing once connected. Prefer a receipt when possible.
  1. Choose the .qev / JSON vault

    The sealed package someone shared with you.

  2. Add the receipt (best)

    Points at the exact on-chain record. Without it you need the issuer wallet and only get “found / not found” for the current hash.

  3. Read the result

    Digest match and status (active / revoked / …) are separate lines — not one vague pass/fail.

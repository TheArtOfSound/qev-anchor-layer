QAL is an open-source anchor and verification layer for QEV encrypted artifacts — not on-chain encryption, not a token, not a notarization service.

Experimental. Do not use for production evidence, legal claims, or security-sensitive custody. Verified builds ≠ audited.

What this is

QEV

Local encrypted envelope. Confidentiality stays offline.

QAL

Public seal: digest, issuer, status, revision lineage.

Solana

Shared evidence ledger for compact commitments only.

Pipeline

File→ QEV encrypt→ SHA-256 digest→ Solana anchor→ Receipt 
digest = SHA-256( UTF-8( canonicalJSON( vault ) ) )

What goes on-chain

Yes

  • Vault digest (32 bytes)
  • Schema hash
  • Issuer / controller
  • Active · revoked · superseded

Never

  • Plaintext
  • Passphrase
  • Keys
  • Sensitive labels

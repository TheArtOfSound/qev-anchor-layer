Put this check in your own app

Not “hash a file and forget it.” Lock an exact file, then check it, replace it, take it back, and show the history. Those verbs already exist in the protocol.

Early. Test networks only. Not audited. Public Solana posting is not live. Don’t ship this as real-world proof yet.

The idea in code

const commitment = await qal.commit({
  vault,
  title: "Treasury Disclosure"
})

await qal.verify(commitment)
await qal.supersede(oldCommitment, newVault)
await qal.revoke(commitment)
await qal.history(commitment)

Same verbs in the command line: 

qal encrypt INPUT --out vault.qev
qal anchor vault.qev --network devnet
qal verify vault.qev --receipt vault.qal-receipt.json
qal history VAULT_DIGEST --issuer PUBKEY
qal revoke ANCHOR_ADDRESS
qal supersede OLD_VAULT NEW_VAULT

What the public record holds

  • A fingerprint that never changes
  • A status that can: stay live, be taken back, be replaced, or be contested
  • Replace is one step: new stamp + old one marked “replaced”
  • Taken back and replaced are final. Status never silently edits the fingerprint.

What never goes public

  • The words
  • The phrase or keys
  • The locked file itself (default is fingerprint only)

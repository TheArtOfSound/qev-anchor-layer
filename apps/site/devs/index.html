Put this check in your own app

Not “hash a file and forget it.” Lock (local) → Fingerprint (public) → Check (anyone). Then replace it, take it back, and show the history. Those verbs already exist in the protocol. No token. No wallet required to check.

The official program is live on Solana’s test network. See the four public transactions. Not audited. Don’t ship this as mainnet or legal proof. A liar can still lock a lie. Studio is practice — not the official QEV vault.

Works today: the command line

This is the shipped path. Copy it and run it against Devnet. 

qal doctor
qal encrypt INPUT --out vault.qev
qal anchor vault.qev --network devnet
qal verify vault.qev --receipt vault.qal-receipt.json
qal history VAULT_DIGEST --issuer PUBKEY
qal revoke ANCHOR_ADDRESS
qal supersede OLD_VAULT NEW_VAULT

Works today: the SDK

These are the real exports of @qira/qal-sdk. The vault is a QEV envelope; the signer is your own keypair — we never hold it. 

import {
  computeVaultDigest,
  anchorVault,
  verifyVaultWithReceipt,
  supersedeVault,
  revokeAnchor,
  walkRevisionHistory,
} from "@qira/qal-sdk";

const { digest } = computeVaultDigest(vault);
const { receipt, signature } = await anchorVault(
  { vault, network: "solana-devnet" },
  signer,
);

const result = await verifyVaultWithReceipt(vault, receipt, {
  connection,
  verifyTransaction: true,
});
// result.outcome === "VALID_ACTIVE"

A shorter qal.commit()-style wrapper is a proposal, not shipped. If you see it in a write-up, it is not in this package yet.

What the public record holds

  • A fingerprint that never changes
  • A status that can: stay live, be taken back, be replaced, or be contested
  • Replace is one step: new stamp + old one marked “replaced”
  • Taken back and replaced are final. Status never silently edits the fingerprint.

What never goes public

  • The words
  • The phrase or keys
  • The locked file itself (default is fingerprint only)

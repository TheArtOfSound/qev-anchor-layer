Boundary

QEV encryption stays local. Solana holds a commitment about the encrypted artifact. Putting the vault on-chain is out of scope.

Digest

validateVaultSchemaV2(vault)
canonical = canonicalJSON(vault)   // sorted keys, no whitespace
digest    = SHA-256(UTF-8(canonical))

Same logical vault → same digest regardless of JSON formatting. One ciphertext byte change → different digest.

CLI

pnpm install && pnpm build
pnpm doctor
# passphrase is prompted — never --password
qal encrypt file.json --out file.qev
qal anchor file.qev --network devnet
qal verify file.qev --receipt file.qal-receipt.json
